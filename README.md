# Awesome Reverse-Engineered

An index of open-source tools, clients, SDKs, drivers and reimplementations that exist because someone **reverse engineered** a closed app, API, protocol, file format, device, game or AI tool.

**10,117 projects** in 20 categories · updated 2026-10-11 · sorted by GitHub stars inside each section. Stars, archived state and dead links are refreshed nightly.

Scope: interoperability, preservation and research. Exploits, jailbreaks, cheats, DRM removal and credential tools are left out on purpose.

## Use it from an AI agent

The repo is also a Claude Code plugin with one skill, [`find-reverse-engineered`](skills/find-reverse-engineered/SKILL.md). When a task needs to talk to a closed app, device, API or file format, the agent searches this index and picks a project by stars, language, license and recent activity. It then reads the README or clones the project.

**Claude Code** (plugin):

```
/plugin install reverse-engineered --marketplace alexgaoth/awesome-reverse-engineered
```

**Claude Code, Cursor, Codex, Gemini CLI, Copilot and other agents** (with Vercel's [`skills`](https://github.com/vercel-labs/skills) CLI):

```bash
npx skills add alexgaoth/awesome-reverse-engineered
```

Any other agent or shell can use the same search script. It has no dependencies:

```bash
curl -sL https://raw.githubusercontent.com/alexgaoth/awesome-reverse-engineered/main/skills/find-reverse-engineered/scripts/re_index.py -o re_index.py
python3 re_index.py search tuya local          # ranked matches
python3 re_index.py info make-all/tuya-local   # entry + README excerpt
python3 re_index.py clone make-all/tuya-local  # shallow clone into vendor/
```

## How this list is built

Research agents (Claude) search GitHub, awesome-lists, Hacker News (Algolia API), Reddit and the web in rounds. Each repo is checked against the GitHub API (it exists, canonical URL, stars, archived flag), duplicates are removed by URL, and the list is regenerated. A [nightly workflow](.github/workflows/refresh.yml) refreshes stars and archived state and removes repos that no longer exist (logged in [`data/removed.json`](data/removed.json)). The raw data is in [`data/entries.json`](data/entries.json); imported lists and search queries are in [SOURCES.md](SOURCES.md).

Corrections and additions are welcome — open an issue or PR.
